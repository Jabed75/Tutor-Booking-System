
# Tutor Booking systems

## Project Overview

Tutor Booking is a web application that helps students find and book experienced tutors for different subjects. Users can explore tutor profiles, book sessions, and manage their bookings through a secure and responsive platform.

## Features

- User authentication with Firebase.
- Browse tutors by subject and category.
- Book tutoring sessions easily.
- Add, update, and manage tutor information.
- Responsive design for mobile, tablet, and desktop.
- Protected private routes for authenticated users.
- Beautiful success and error notifications without using default alerts.

## Technologies Used

- React.js
- React Router DOM
- Tailwind CSS
- DaisyUI
- Firebase Authentication
- Node.js
- Express.js
- MongoDB
